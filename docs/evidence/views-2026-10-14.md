# Gestion des vues — 14 octobre 2026

Comportements observés dans la copie dbdiagram fournie par l’utilisateur : création vide, recherche sur toutes les tables, action de groupe sur tous ses membres malgré le filtre, renommage dans la liste, confirmation de suppression, Save/Reset et Save as New. Écart demandé : proposer Enregistrer / Abandonner / Annuler avant de quitter une vue dont la visibilité est modifiée.

## Implémentation

- Vue système permanente `all`, libellée Default View ; renommage et suppression absents de ses commandes.
- Sélecteur compact avec création vide, renommage dans la liste et confirmation de suppression.
- Prévisualisation de visibilité séparée de la présentation enregistrable du projet. Les modifications du diagramme conservent positions et détail sans valider la prévisualisation.
- Validation de la visibilité synchronisée avec la section Tables du DiagramView DBML ; le texte extérieur à cette section est conservé.
- Save as New conserve le diagramme affiché ; avertissement lors du changement de vue, y compris une navigation DBML exigeant le retour à Default View.
- Niveau de détail uniquement dans la barre flottante ; état vide et liste complète des tables dans les vues personnalisées.
