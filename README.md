# dbcodex

`dbcodex` est un projet open source de plugin pour Codex destiné à ouvrir, valider et visualiser des fichiers DBML directement dans Codex, puis à terme à permettre leur modification.

**Statut : Product discovery / design**

Le projet ne contient encore aucune implémentation. Le développement commencera uniquement après validation du périmètre fonctionnel et de l’architecture.
